# my-khorezm.uz

**Xorazm — tarix, tabiat va zamonaviy hayot** (`my-khorezm.uz`) — Xorazm viloyatiga bag‘ishlangan ko‘p tilli (**UZ / RU / EN**) raqamli ensiklopediya va axborot portali.

## Asosiy imkoniyatlar

- **Geografiya va ekologiya**: Amudaryo, iqlim, tuproq, flora va fauna hamda **Open-Meteo** orqali real vaqtda Urganch ob-havosi va havo sifati (AQI / PM2.5 / PM10).
- **Tarix va sivilizatsiya**: Qadimgi Xorazm, Xorazmshohlar imperiyasi, Xiva xonligi va 1920–hozirgi davr xronologiyasi.
- **13 ta shahar va tuman**: `xorazmstat.uz` (2025) va Wikipedia ma’lumotlari asosidagi aniq statistik ko‘rsatkichlar va fotosuratlar.
- **Turizm, madaniyat va taomlar**: Ichan-Qal’a yodgorliklari, Lazgi, mashhur allomalar, milliy taomlar retseptlari va Xorazm shevasi lug‘ati.
- **Media, TV va Radio**: Ochiq MTRK HLS telekanallari, FM radiostansiyalar, 360° panoramalar hamda to‘liq ekranli **ImageLightbox** fotogalereyasi.
- **Loyihaga hissa (Donat) + PDF tashakkurnoma**: Ism-familiya yozilgan A4 o‘lchamdagi tashakkurnoma PDF generatsiyasi.
